### Flagship Projects

#### [Cipher](https://github.com/insaneodyssey26/cipher) - Offline Personal Finance
Automated bank SMS and notification parsing engine with zero network transmission. Encrypted at rest with SQLCipher AES-256-GCM and hardware-backed Android Keystore keys. Features multi-region parsing rules backed by 420+ automated tests and six Glance widgets.

> 0 network permissions requested. Because your transaction history is none of my business.

`Kotlin` · `Jetpack Compose` · `MVI` · `Hilt` · `Room` · `SQLCipher` · `Glance` · `WorkManager`  
[Google Play](https://play.google.com/store/apps/details?id=com.masum.cipher) · [Source Code](https://github.com/insaneodyssey26/cipher) · [Case Study](https://masum.tech/projects/cipher)

---

#### [Vigil](https://github.com/insaneodyssey26/vigil) - On-Device DNS Telemetry & Tracker Inspector
Zero-root network telemetry inspector using a local `VpnService` tunnel. Dissects raw UDP DNS packets in real-time, attributing queries to specific apps and classifying lookups against 90,000+ tracker domains using an in-memory reverse-label suffix trie.

> It audits everything your chatty apps do, but never blocks. We observe, we do not judge.

`Kotlin` · `Jetpack Compose` · `VpnService` · `Suffix Trie` · `Hilt` · `Room` · `Multi-Module Gradle`  
[Releases](https://github.com/insaneodyssey26/vigil/releases) · [Source Code](https://github.com/insaneodyssey26/vigil) · [Case Study](https://masum.tech/projects/vigil)

---

#### [Fathom](https://github.com/insaneodyssey26/fathom) - Minimalist Philosophy Reader
Distraction-free classic literature reader indexing 15,160+ canonical passages across 7 philosophical traditions. Features a shared Kotlin Multiplatform core, dual SQLDelight databases with SHA-256 verified content packs, and ambient audio soundscapes.

> Search takes under 5 ms; understanding the texts takes a lifetime.

`Kotlin Multiplatform` · `Jetpack Compose` · `SQLDelight` · `Media3 / ExoPlayer` · `SHA-256` · `StateFlow`  
[Releases](https://github.com/insaneodyssey26/fathom/releases) · [Source Code](https://github.com/insaneodyssey26/fathom) · [Case Study](https://masum.tech/projects/fathom)
